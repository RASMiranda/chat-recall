# Chat Recall

Fast, local, full-text search across **all** your claude.ai chats, scoped to **a project** or to **one chat**. Chrome and Firefox (Manifest V3). English UI. MIT licensed. No servers, no accounts, no Claude/API usage.

> Unofficial. Not affiliated with or endorsed by Anthropic. It reads claude.ai's undocumented internal web API with your own logged-in session, so it can break whenever claude.ai changes. See "Known risks".

## Use

- Press **Ctrl+K** (⌘K on Mac) on any claude.ai page.
- Type words. All words must appear somewhere in the chat (title or any message). Case and accents are ignored.
- Operators: `"exact phrase"`, `-exclude`, `from:me`, `from:claude`, `since:2025-01-01`, `since:7d`, `until:30d` (units `d w m y`).
- Scope buttons: **All chats**, **This project** (on a project page, or in a chat that belongs to one), **This chat** (lists each matching message and scrolls to it).
- Every result shows the chat URL (`https://claude.ai/chat/<id>`) with a **Copy link** button. Enter opens it; Ctrl/⌘+Enter opens a new tab. After opening, the page scrolls to the first matching text.
- Toolbar icon: index status, **Sync now**, **Rebuild index**, **Clear index**, auto-sync toggle.

The first sync reads every chat once (3 at a time, with backoff); later syncs fetch only chats whose `updated_at` changed. Results appear as indexing progresses.

## Install

**Firefox:** install from [addons.mozilla.org](https://addons.mozilla.org/en-US/firefox/addon/chat-recall/).

## Install for testing

**Chrome / Edge:** `chrome://extensions` → Developer mode → *Load unpacked* → select `dist/chrome`.
**Firefox:** `about:debugging#/runtime/this-firefox` → *Load Temporary Add-on* → select `dist/firefox/manifest.json`. After installing, open `about:addons` → Chat Recall → **Permissions** and make sure access to claude.ai is **on** (Firefox treats host access as optional for MV3 extensions; if it is off nothing appears).

## Build and test

```bash
npm test                      # unit tests (search, API parsing, sync engine)
npm run build                 # dist/chrome, dist/firefox + zips
npm run lint:firefox          # web-ext lint on the Firefox build
npm i --no-save jsdom && node scripts/smoke-ui.js   # UI smoke test with a fake claude.ai API
```

No runtime dependencies and no bundler; the manifests are generated by `scripts/build.js`.

## How it works

- `src/api.js` – finds your organization id (cookie → `/api/organizations` → `/api/bootstrap`), lists chats (`/api/organizations/{org}/chat_conversations`), fetches each chat, extracts message text (thinking/tool blocks skipped).
- `src/sync.js` – incremental sync with retry/backoff; 401/403 stops cleanly with a "sign in" status.
- `src/store.js` – `storage.local` (with `unlimitedStorage`); one key per chat.
- `src/search.js` – length-preserving case/accent folding, query parser, ranking, snippets with highlight ranges.
- `src/content.js` – hotkey, palette (closed shadow DOM, no `innerHTML` with chat text), in-page jump.

## Known risks / unverified

- **Internal API shape.** Endpoint paths and field names (`name`, `updated_at`, `chat_messages`, `project_uuid`) come from public third-party tools and were not verified against your live account. The parsers are defensive and unit-tested against mock data, but a real-account test is still needed.
- **Project membership** is the least certain part. The extension looks for `project_uuid` on the chat list, then on each chat, then falls back to `/projects/{id}/conversations`. If none of these exist the project scope will be empty and the palette says so.
- **Message-level URLs:** claude.ai has no per-message links that I know of; results link to the chat and the page scrolls to the matching text.
- **Deleted chats** are not removed automatically (the list endpoint's pagination is unverified); use *Rebuild index* to refresh.
- **Terms of service:** automated access to claude.ai's internal API may not be permitted by Anthropic's terms. Check before publishing.
- Very large histories (many MB of text) are held in memory for fast search; expect tens of MB of RAM on 1000+ long chats.
